## Introduction

[Singapore]({{ 'where-does-singapore-keep-its-strangest/' | relative_url }})'s most remarkable scientific curiosity is not a single spectacular skeleton or preserved animal on public display, but an immense research archive hidden behind the galleries of the Lee Kong Chian Natural History Museum. More than one million zoological specimens, collected over well over a century, form one of Southeast Asia's most important biodiversity collections. Individually, many specimens appear ordinary: a fish in alcohol, a pinned insect, a bird skin or a crab in a jar. Collectively, however, they become scientific evidence. Every specimen links a physical organism to information about where, when and how it was collected, allowing researchers to reconstruct changing ecosystems, verify species identities, describe new species and measure environmental change across decades. Rather than preserving curiosities for their own sake, Singapore's zoological archive demonstrates how carefully documented collections transform dead animals into enduring records of the natural world.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

## What Can a Million Preserved Animals Reveal?

The Lee Kong Chian Natural History Museum is best known to visitors for its dinosaur skeletons and dramatic whale display, yet these exhibits represent only a tiny fraction of its holdings. Behind the public galleries lies the Zoological Reference Collection (ZRC), an internationally recognised research archive containing more than one million specimens representing at least 10,000 species, the majority originating from Southeast Asia. Many collections—including freshwater fishes, birds and decapod crustaceans—are regarded as among the strongest regional reference collections available to scientists.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

Unlike display specimens chosen to impress visitors, reference collections exist to answer scientific questions. Researchers use them to:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* confirm the identity of species;
* compare newly collected animals with historical examples;
* document the geographical distribution of wildlife;
* detect environmental and ecological change over long periods;
* describe species previously unknown to science;
* preserve evidence that can be re-examined as scientific methods improve.

</div>

The collection therefore functions less like a traditional museum gallery than a continuously expanding scientific database built from physical evidence. Even specimens collected more than a century ago remain valuable because they can be revisited using techniques—including DNA analysis and advanced imaging—that were unimaginable when they were first preserved.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

## Inside the Zoological Reference Collection

The archive contains a remarkable diversity of preserved material rather than one dominant collection type. Wet specimens stored in alcohol preserve soft tissues and internal anatomy. Bird skins and mammal specimens retain external features useful for comparison. Skeletons reveal anatomical structure, while microscopic organisms, insects, crustaceans, molluscs and fishes are stored using preservation methods suited to each group. Together they create a comprehensive reference library of Southeast Asian biodiversity.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

Many of these specimens are historically irreplaceable. Some were collected before extensive urbanisation transformed Singapore's landscape, recording habitats that have since disappeared or changed dramatically. Others come from scientific expeditions across Southeast Asia, documenting ecosystems that are now under pressure from development, pollution or climate change. Because specimens are permanent records, researchers can repeatedly extract new information without needing to relocate the original populations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

The collection also contains many unsorted or partially processed holdings gathered during biodiversity surveys. Although these lack the immediate visibility of catalogue specimens, they represent future research potential as taxonomists continue identifying and describing material collected from across the region.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

## How Labels Turn Bodies into Evidence

A preserved animal without documentation has limited scientific value. The evidence comes from the information attached to it.

Each research specimen ideally carries detailed metadata including:


<div class="content-enhancement content-enhancement--phrase-stack" markdown="1">

* precise collection locality;
* collection date;
* collector's identity;
* habitat description;
* preservation method;
* taxonomic identification;
* catalogue number linking the specimen to museum records.

</div>

This documentation allows scientists to verify claims rather than relying on memory or published descriptions alone. If taxonomic classifications change—as they frequently do—the original specimen can be re-examined. If researchers question where a species once occurred, the specimen's locality data provide independently verifiable evidence.

The importance of systematic documentation has been recognised in Singapore for well over a century. Curators of the former Raffles Library and Museum argued during the late nineteenth century that specimens required clear collecting objectives and accurate records rather than being assembled simply as cabinets of interesting objects. That philosophy remains fundamental to the museum's scientific role today.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.roots.gov.sg/stories-landing/stories/learning-through-looking-the-natural-history-collection-of-the-former-raffles-library-and-museum/story" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: roots.gov.sg">[Roots]</a><span class="citation-popover" role="note"><span class="citation-popover-source">roots.gov.sg</span><span class="citation-popover-snippet">Learning Through Looking: The Natural History Collection of the Former Raffles Library and MuseumOctober 15, 2020...</span><span class="citation-popover-meta">Published: October 15, 2020</span></span></span>

## Saving Singapore's Natural-History Archive

The scientific collection has survived repeated institutional changes that could easily have dispersed or destroyed it.

Natural history specimens first entered the collections of the Raffles Library and Museum during the nineteenth century, where mounted animals, skeletons and preserved specimens formed the institution's dominant displays. As Singapore's museum landscape evolved, the zoological collections eventually moved to what is now the National University of Singapore, reopening in 1988 as the Zoological Reference Collection before becoming the foundation of today's Lee Kong Chian Natural History Museum.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/our-story/museum-history/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[edu.sg]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMMuseum History</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

The continuity of the collection is scientifically significant. Long-running archives gain value precisely because they preserve consistent records across generations. A specimen collected in the early twentieth century can now be compared directly with material gathered from the same locality today, allowing researchers to detect shifts in species ranges, body size, genetic diversity or habitat condition that would otherwise remain invisible.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/our-collections/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMAbout the Zoological Reference Collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

Equally important are the museum's supporting archives. Field notebooks, accession registers, catalogue cards, photographs and correspondence preserve the context in which specimens were collected. These documentary collections help modern researchers interpret older material whose significance might otherwise be lost, linking biological evidence with the history of scientific exploration in Singapore and Southeast Asia.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://lkcnhm.nus.edu.sg/research/library-and-archive-sub-collection-2/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: lkcnhm.nus.edu.sg">[NUS LKCNHM]</a><span class="citation-popover" role="note"><span class="citation-popover-source">lkcnhm.nus.edu.sg</span><span class="citation-popover-title">NUS LKCNHMLibrary and Archive Sub-collection</span><span class="citation-popover-snippet">NUS LKCNHM...</span></span></span>

## Why This Archive Matters Beyond the Museum

Natural-history collections are sometimes mistaken for static warehouses of preserved animals. In reality, they function as active scientific infrastructure.

Specimens support biodiversity surveys, conservation planning, environmental impact studies and taxonomic research. Historical records help establish whether species are native, introduced or locally extinct, while authenticated reference material allows scientists worldwide to compare newly collected animals against verified examples.     var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>

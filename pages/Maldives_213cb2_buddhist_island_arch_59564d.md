## Introduction

The [Maldives]({{ 'maldives/' | relative_url }}) is famous for turquoise lagoons and coral reefs, yet beneath many inhabited islands lies a far older cultural landscape. Long before the islands became an Islamic sultanate in the twelfth century, they supported Buddhist monasteries, ritual complexes and carved monuments. Much of this heritage is no longer visible because centuries of rebuilding, coral reuse, erosion and modern development have buried or dismantled ancient structures. Archaeological surveys over the past decade have transformed understanding of this hidden landscape by combining excavation, GPS mapping, laser scanning and three-dimensional digital recording. These projects reveal that what often appears to be an ordinary village or low mound may conceal the remains of substantial Buddhist architecture and inscriptions, offering one of the Maldives' most intriguing archaeological stories.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

## What Lies Beneath the Maldives' Island Settlements?

Unlike the stone temples of South Asia, most Maldivian Buddhist monuments were built with locally available coral stone. Coral was relatively easy to shape when freshly quarried but became durable after drying, making it well suited for monuments, sculptures and carved architectural blocks. Over many centuries, however, these same materials were reused in later buildings, particularly after the islands adopted Islam, leaving only fragments of the earlier ritual landscape visible today.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://whc.unesco.org/en/tentativelists/5812/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: whc.unesco.org">[UNESCO World Heritage Centre]</a><span class="citation-popover" role="note"><span class="citation-popover-source">whc.unesco.org</span><span class="citation-popover-title">World Heritage Centre Coral Stone Mosques of Maldives</span><span class="citation-popover-snippet">UNESCO World Heritage CentreCoral Stone Mosques of Maldives - UNESCO World Heritage CentreFebruary 19, 2013...</span><span class="citation-popover-meta">Published: February 19, 2013</span></span></span>

Many archaeological sites survive as low artificial mounds, traditionally called *havitta* or similar local names. From the surface they may resemble natural rises in otherwise flat islands, but surveys have shown that these mounds frequently conceal the foundations of stupas, monasteries, image houses and ceremonial platforms. Their modest appearance explains why the scale of Maldivian Buddhist archaeology remained underestimated for much of the twentieth century.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

For visitors interested in unusual heritage, this creates a distinctive experience. Rather than dramatic standing ruins, the fascination comes from recognising that everyday settlements often occupy landscapes layered with centuries of forgotten religious architecture.

## Buddhist Ruins and Carved Coral Discoveries

One of the clearest examples comes from Gan in Laamu Atoll. Early explorer H. C. P. Bell mapped nine structures there in the 1920s, but the recent Maldives Heritage Survey documented dozens more architectural remains and earthworks, revealing a much larger ritual complex than previously recognised. Digital mapping has shown how temples, monastic buildings and ceremonial spaces formed an organised religious centre rather than isolated ruins.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

Among the most remarkable discoveries from Gan is a carved coral stone block featuring a fierce face on one side and a Sanskrit Buddhist inscription on the reverse. The inscription incorporates elements associated with Vajrayana Buddhist mantras, providing rare written evidence for the religious traditions practised in the Maldives during the late first millennium CE. The object was accidentally uncovered during construction work in 2018 and suffered damage before archaeologists could recover it, illustrating how vulnerable buried archaeology remains. The survey team subsequently produced a detailed three-dimensional model so that researchers could study it without further handling.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://maritimeasiaheritage.cseas.kyoto-u.ac.jp/recent-publications-on-the-maldives/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: maritimeasiaheritage.cseas.kyoto-u.ac.jp">[Maritime Asia Heritage Survey]</a><span class="citation-popover" role="note"><span class="citation-popover-source">maritimeasiaheritage.cseas.kyoto-u.ac.jp</span><span class="citation-popover-title">Maritime Asia Heritage Survey RECENT PUBLICATIONS ON THE MALDIVES</span><span class="citation-popover-snippet">Maritime Asia Heritage SurveyRECENT PUBLICATIONS ON THE MALDIVES - Maritime Asia Heritage SurveyJune 28, 2021...</span><span class="citation-popover-meta">Published: June 28, 2021</span></span></span>

Another major complex was documented on Fuvamulah, where archaeologists identified a large Buddhist sanctuary containing stupas and associated structures surrounding an artificial mound. Particularly significant is the relationship between these Buddhist remains and later Islamic monuments nearby. Rather than existing in complete isolation, the archaeological landscape preserves evidence of successive religious traditions occupying the same island over many centuries.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

## What Inscriptions Reveal About Island Society

Written evidence from the Buddhist period is scarce, making every inscription especially valuable. The Sanskrit inscription found on Gan demonstrates that the Maldives was connected to wider Indian Ocean religious networks rather than existing as an isolated island culture. Its language and religious formulae point towards links with Buddhist traditions extending across Sri Lanka and South Asia.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

The archaeology also suggests that Buddhist communities invested considerable labour in monumental construction despite the islands' limited natural resources. Artificial mounds, carefully shaped coral blocks and planned religious compounds imply organised communities capable of coordinating specialised craftsmanship. These findings challenge older assumptions that pre-Islamic Maldives consisted only of small, loosely connected settlements with little architectural ambition.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

Coral carving itself provides another important clue. Techniques later celebrated in the Maldives' famous coral-stone mosques appear to have evolved from earlier Buddhist craftsmanship. Decorative forms changed after conversion to Islam, but many construction methods, stone-working skills and architectural concepts continued, creating an important thread of continuity across a major religious transformation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://whc.unesco.org/en/tentativelists/5812/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: whc.unesco.org">[UNESCO World Heritage Centre]</a><span class="citation-popover" role="note"><span class="citation-popover-source">whc.unesco.org</span><span class="citation-popover-title">World Heritage Centre Coral Stone Mosques of Maldives</span><span class="citation-popover-snippet">UNESCO World Heritage CentreCoral Stone Mosques of Maldives - UNESCO World Heritage CentreFebruary 19, 2013...</span><span class="citation-popover-meta">Published: February 19, 2013</span></span></span>

## How Digital Surveys Preserve Fragile Sites

Traditional excavation cannot keep pace with the threats facing Maldivian archaeology. Coastal erosion, land reclamation, construction projects and climate-related environmental change all place buried sites at risk. Because many remains survive only as shallow subsurface features or scattered coral fragments, detailed digital recording has become one of the most important preservation tools.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ora.ox.ac.uk/objects/uuid%3A3e3369f1-fd1a-4c62-8cb8-f5a29ea50ecc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ora.ox.ac.uk">[Oxford University Research Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ora.ox.ac.uk</span><span class="citation-popover-title">Oxford University Research Archive Maldives Heritage Survey</span><span class="citation-popover-snippet">ford University Research ArchiveMaldives Heritage Survey - ORA - Oxford University Research Archive...</span></span></span>

<span class="citation-chip-wrap"><a class="citation-chip" href="https://www.oxcis.ac.uk/maldives-heritage-survey" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: oxcis.ac.uk">[Maldives Heritage Survey]</a><span class="citation-popover" role="note"><span class="citation-popover-source">oxcis.ac.uk</span><span class="citation-popover-title">Maldives Heritage Survey &#124; Oxford Centre for Islamic Studies</span><span class="citation-popover-snippet">Maldives Heritage Survey &#124; Oxford Centre for Islamic Studies</span></span></span> rvey systematically recorded endangered monuments using:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* High-resolution digital photography.
* Terrestrial laser scanning.
* Three-dimensional photogrammetric models.
* Geographic Information System (GIS) mapping.
* Open-access digital databases for researchers and heritage managers.

</div>

Together these techniques create permanent records even if physical remains deteriorate in the future. They also allow scholars to compare dispersed sites across multiple atolls, revealing regional settlement patterns that would be difficult to recognise from isolated excavations alone.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ora.ox.ac.uk/objects/uuid%3A3e3369f1-fd1a-4c62-8cb8-f5a29ea50ecc" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ora.ox.ac.uk">[Oxford University Research Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ora.ox.ac.uk</span><span class="citation-popover-title">Oxford University Research Archive Maldives Heritage Survey</span><span class="citation-popover-snippet">ford University Research ArchiveMaldives Heritage Survey - ORA - Oxford University Research Archive...</span></span></span>

Digital recording has another public benefit. Three-dimensional models enable museum visitors, students and researchers to examine fragile carvings and inscriptions in far greater detail than would normally be possible with original artefacts kept in storage or protected from handling.

## Why So Little Is Visible Today

Many readers expect Buddhist temples to survive as standing monuments, yet the Maldives presents a very different archaeological picture.

Several factors explain why the landscape appears almost empty today:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Coral stone was frequently reused in later construction.
* Ancient monuments were dismantled after the islands adopted Islam.
* Tropical weather rapidly erodes exposed coral architecture.
* Dense vegetation and modern settlement obscure archaeological features.
* Limited early archaeological excavation left many sites only partially investigated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[Cambridge University Press &amp; Assessment]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

The result is an archaeological landscape where the most important discoveries often emerge during careful survey rather than spectacular excavation. Modern mapping technologies are therefore revealing sites that had remained effectively invisible despite being known locally for generations.

## Why This Hidden Landscape Matters

The buried Buddhist archaeology of the Maldives represents far more than a forgotten religious chapter. It documents how an island society participated in Indian Ocean networks of belief, trade and artistic exchange while adapting imported traditions to a unique coral environment. The surviving carvings, inscriptions and ritual mounds also explain the origins of later Maldivian stone craftsmanship, showing that some of the techniques admired in medieval coral mosques have much deeper roots.

Within the Maldives' landscape of unusual heritage, these sites are distinctive because their greatest treasures are often concealed beneath ordinary ground. Their significance lies not in monumental ruins dominating the skyline but in the patient reconstruction of a lost world through scattered coral blocks, buried foundations, Sanskrit inscriptions and increasingly sophisticated digital archaeology.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cambridge.org/core/journals/antiquity/article/maldives-heritage-survey/15F61521DF052F7FEA4CA8AEEEA554FC" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cambridge.org">[cambridge.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cambridge.org</span><span class="citation-popover-snippet">Cambridge University Press &amp; AssessmentThe Maldives Heritage Survey &#124; Antiquity &#124; Cambridge CoreApril 22, 2021...</span><span class="citation-popover-meta">Published: April 22, 2021</span></span></span>

    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
})();

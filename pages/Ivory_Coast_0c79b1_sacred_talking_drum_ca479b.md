## Introduction

The return of the Djidji Ayôkwé in March 2026 transformed a single artefact into one of the most important cultural restitution stories in West Africa. Confiscated by French colonial authorities in 1916 and kept in French museum collections for more than a century, the monumental talking drum is not simply an old musical instrument. For the Atchan people around Abidjan, it represents political authority, spiritual legitimacy and collective memory. Its return therefore raises an unusual question: can an object regarded as sacred and socially active ever become just another museum exhibit? The answer, in [Ivory Coast]({{ 'where-ivory-coast-keeps-its-strangest/' | relative_url }}), is increasingly that it cannot. Instead, the drum has become a case study in balancing ritual traditions with the practical demands of conservation, public display and national heritage policy.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[unesco.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

## How the Djidji Ayôkwé carried messages

Unlike the hand-held talking drums found elsewhere in West Africa, the Djidji Ayôkwé is a monumental slit drum carved from a single iroko tree. Measuring more than three metres long and weighing around 430 kilograms, it was designed to project powerful rhythmic patterns over long distances between Atchan villages around present-day Abidjan.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[UNESCO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

Its purpose extended far beyond music. The drum functioned as a public communication system, announcing ceremonies, summoning village leaders, warning of danger and coordinating collective action. Oral tradition and historical accounts describe it as capable of transmitting recognisable coded messages across many kilometres, making it an essential instrument of governance rather than entertainment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Djidji_Ayokwe" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Djidji Ayokwe</span><span class="citation-popover-snippet">Djidji Ayokwe</span></span></span>

This practical role also gave the drum political importance. During the colonial period it reportedly warned communities about forced labour recruitment and other interventions by French authorities. Because it could rapidly mobilise people, colonial administrators regarded it as a strategic instrument of resistance rather than merely a ceremonial object. That political significance helps explain why it became a target for confiscation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[unesco.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

## Confiscation, exile and return

In 1916, during a French colonial campaign against resistance in the Abidjan region, the Djidji Ayôkwé was seized from the Atchan community. Removing the drum was not only the loss of a cultural object but also the removal of a traditional communication network and an important symbol of local authority.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[UNESCO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

The drum was eventually transferred to France, where it entered the national collections and spent decades in institutions including the Musée de l'Homme before becoming part of the Musée du quai Branly – Jacques Chirac. Within the museum context it was catalogued, conserved and interpreted primarily as an ethnographic object, even though its original community regarded it as something with continuing ceremonial significance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[UNESCO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

Its return did not happen quickly. Restitution discussions gathered momentum after France announced a broader policy of returning selected colonial-era cultural property to African nations. The process required diplomatic negotiations, scientific conservation work, new French legislation and consultation with Atchan traditional authorities. The official handover took place in Paris in February 2026, and the drum arrived in Abidjan on 13 March 2026, becoming the first artefact formally returned from France to Côte d'Ivoire.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[unesco.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

The arrival itself was treated as more than a museum delivery. Government officials, traditional chiefs and cultural representatives welcomed the drum in a formal ceremony that presented its return as the recovery of part of the country's historical identity rather than simply an expansion of a museum collection.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://gouv.ci/actualite/restitution-de-biens-culturels-ivoiriens-le-tambour-parleur-djidji-ayokwe-du-peuple-atchan-officiellement-de-retour-sur-la-terre-de-ses-ancetres-2710" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: gouv.ci">[gouv.ci]</a><span class="citation-popover" role="note"><span class="citation-popover-source">gouv.ci</span><span class="citation-popover-snippet">Government of Côte d&#x27;IvoireCôte d&#x27;Ivoire - Portail officiel du Gouvernement:: Actualités - Société...</span></span></span>

## Why this is not an ordinary museum object

The Djidji Ayôkwé illustrates a challenge increasingly faced by museums holding sacred heritage. Standard museum practice assumes that objects can be documented, stabilised, displayed and interpreted primarily as physical artefacts. The Atchan understanding is different.

For many members of the community, the drum derives meaning from its role within ritual authority, customary leadership and collective memory. Its significance cannot be separated from the ceremonies, restrictions and social relationships that traditionally governed its use. A climate-controlled display case may preserve the wood, but it cannot fully preserve the cultural role that originally gave the object its authority.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/articles/return-djidji-ayokwe-emblematic-example-cultural-cooperation-between-france-and-cote-divoire?hub=200006" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[UNESCO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Return of the Djidji Ayôkwé: an emblematic example of cultural</span><span class="citation-popover-snippet">Return of the Djidji Ayôkwé: an emblematic example of culturalFebruary 20, 2026...</span><span class="citation-popover-meta">Published: February 20, 2026</span></span></span>

This distinction also shaped the restitution process itself. Reports indicate that Atchan traditional leaders carried out rituals connected with the drum before it could leave France, reflecting the view that sacred responsibilities remained attached to the object even while it was overseas. Such actions demonstrate that restitution involved cultural protocol as well as legal ownership.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://apnews.com/article/f6a5c6b75eb11655dfe1883519eb91fe" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: apnews.com">[AP News]</a><span class="citation-popover" role="note"><span class="citation-popover-source">apnews.com</span><span class="citation-popover-snippet">The drum, a significant communication tool used by the Atchan people, was taken by French colonial authorities in 1916. ## Ritual authority versus museum conservation

The current plan places the drum within the Museum of Civilisations in Abidjan, but not as an ordinary exhibit. Conservation specialists must protect a large, centuries-old wooden object that has spent decades in a different climate. ## Why the return matters within Ivory Coast's curiosity heritage

For travellers interested in Ivory Coast's unusual heritage, the Djidji Ayôkwé stands apart because it blurs the boundary between museum object and living cultural presence. It is simultaneously:

* a monumental communication device rather than a conventional musical instrument;
* a sacred object associated with traditional authority;

* a museum artefact requiring advanced conservation;

    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
